### S04　模型與三條誤差假設
- 類型：內容頁（上公式、下三張卡片）
- 標題：模型與三條誤差假設
- 一句話訊息：SLR 把 $Y_i$ 寫成一條直線加上誤差，誤差只需滿足三條假設。
- 公式：$Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i,\quad i = 1,\dots,n$
- 內容：
  - $X_i$ 視為固定、已知的數
  - $\beta_0, \beta_1$ 是未知但固定的參數
  - $\varepsilon_i$ 是隨機誤差，此時還沒假設分配
- 卡片：三張一般卡「① 平均為 0：$E(\varepsilon_i)=0$」「② 變異數相同：$Var(\varepsilon_i)=\sigma^2$」「③ 不相關：$Cov(\varepsilon_i,\varepsilon_j)=0,\ i\ne j$」
- 出處：[[simple-linear-regression]]、[[slr-error-assumptions]] ← Lecture 02 p.2
- 講者備註：「平均為 0」不是每個誤差都很小，個別誤差可大可小。三條假設可以對應到 $Y_i$ 的平均、變異數、共變異數，下一頁並排寫。
- 補充：否

### S05　Y 的分配：電器經銷商
- 類型：內容頁（左文右圖）
- 標題：$Y_i$ 的分配：電器經銷商
- 一句話訊息：每個 $X$ 都有自己的 $Y$ 分配，平均落在迴歸線上，誤差就是偏離平均的量。
- 公式：$E(Y_i\mid X_i)=\beta_0+\beta_1X_i,\quad Var(Y_i\mid X_i)=\sigma^2,\quad Cov(Y_i,Y_j)=0$
- 內容：
  - 例：$E(Y\mid X)=9.5+2.1X$（$X$ 標案件數、$Y$ 工時）
  - 某週 $X_i=45$：$E(Y_i)=9.5+2.1(45)=104$
  - 實際 $Y_i=108$，誤差 $\varepsilon_i=108-104=4$
- 卡片：key「💡 直覺：母體可以看成很多子母體，每個 $X$ 一個」
- 圖：迴歸線上在三個 $X$ 各畫一個寬度相同的分配，標出 $X=45$ 的平均 104 與觀測 108（示意圖）
- 出處：[[simple-linear-regression]]、[[electrical-distributor]] ← Lecture 02 p.2–3
- 講者備註：這裡參數是「已知」的假想情境，實務上要從資料估計。可以讓學生自己算 $X=30$ 的平均工時。
- 補充：否

### S06　為什麼叫「線性」？
- 類型：內容頁（左文右黑卡）
- 標題：為什麼叫「線性」？
- 一句話訊息：線性指的是對參數 $\beta$ 線性，不是 $Y$ 和 $X$ 畫出來是直線。
- 內容：
  - $Y=\beta_0+\beta_1e^X+\varepsilon$：線性模型
  - 多項式 $Y=\beta_0+\beta_1X+\beta_2X^2+\beta_3X^3+\varepsilon$：線性模型
  - $Y=\beta_0+X^{\beta_1}+\varepsilon$：非線性模型
  - 對參數和 $X$ 都線性：一階模型
- 卡片：dark「⚠️ 誤解：曲線關係就不能用線性模型」
- 出處：[[simple-linear-regression]]、[[linear-means-straight-line]] ← Lecture 02 p.4
- 講者備註：判斷方法：把參數當未知數，若平均函數是「參數 × 已知的 $X$ 函數」相加，就是線性模型。
- 補充：否

### S07　練習 1：線性還是非線性？
- 類型：練習頁
- 標題：練習 1：線性還是非線性？
- 一句話訊息：只看參數出現在哪裡，就能判斷模型是不是線性。
- 內容：
  - 判斷下列五個模型對參數是否線性
- 表格：

  | 題 | 模型 |
  |---|---|
  | 1 | $Y=\beta_0+\beta_1\log X+\varepsilon$ |
  | 2 | $Y=\beta_0+\beta_1X+\beta_2X^2+\varepsilon$ |
  | 3 | $Y=\beta_0e^{\beta_1X}+\varepsilon$ |
  | 4 | $Y=\beta_0+\beta_1(1/X)+\varepsilon$ |
  | 5 | $Y=\beta_0+X^{\beta_1}+\varepsilon$ |

- 答案（折疊）：1 線性（$Z=\log X$）；2 線性（多項式）；3 非線性（$\beta_1$ 在指數裡）；4 線性（$Z=1/X$）；5 非線性
- 卡片：key「✏️ 提示：每個參數是否只乘上一個已知的 $X$ 函數？」
- 出處：[[linear-model-01]]（補充題）← Lecture 02 p.4
- 講者備註：給學生 2 分鐘，再請人說出第 3 題為什麼不是線性。
- 標籤：補充
- 補充：是

### S08　參數的意義
- 類型：內容頁（左文右卡片）
- 標題：參數的意義
- 一句話訊息：斜率是 $X$ 加 1 時 $Y$ 平均的變化；截距只有在 $X=0$ 合理時才有意義。
- 公式：$E(Y\mid X=x+1)-E(Y\mid X=x)=\beta_1$
- 內容：
  - $\beta_1$：$X$ 增加 1 單位，$Y$ 的平均變化量
  - $\beta_0$：$X=0$ 時 $Y$ 的平均
  - 例：多 1 件標案，平均工時多 2.1 小時
  - 模型只適用每週 20–80 件，9.5 沒有獨立意義
- 卡片：key「📌 重點：要說「$Y$ 的平均增加 $\beta_1$」，不是「$Y$ 增加 $\beta_1$」」
- 出處：[[simple-linear-regression]]、[[electrical-distributor]]、[[intercept-always-meaningful]] ← Lecture 02 p.4–5
- 講者備註：截距解讀其實是一種外插；第 2 章的身高體重例題會看到更誇張的截距。
- 補充：否

### S10　這麼多條線，選哪一條？
- 類型：內容頁（左文右圖）
- 標題：這麼多條線，選哪一條？
- 一句話訊息：最小平方法選的是讓垂直距離平方和最小的那條線。
- 公式：$Q=\sum_{i=1}^n(Y_i-\beta_0-\beta_1X_i)^2$
- 內容：
  - 每個點到直線的垂直距離就是誤差
  - 直接相加會正負抵消
  - 絕對值也可以，但平方容易微分、估計量性質好
  - 讓 $Q$ 最小的 $b_0, b_1$ 就是最小平方估計
- 圖：同一組點上兩條候選線，各點殘差畫成正方形，比較面積總和（示意圖）
- 出處：[[least-squares]] ← Lecture 02 p.5–6
- 講者備註：學生常問為什麼不用絕對值：平方可以微分、解有公式，估計量也有很多好性質（第 3 章）。
- 補充：否

### S11　推導：正規方程式
- 類型：推導頁（步驟式）
- 標題：推導：正規方程式
- 一句話訊息：對 $Q$ 偏微分令為 0，解兩條正規方程式就得到 $b_0$、$b_1$。
- 公式：
  - 步驟 1：$\dfrac{\partial Q}{\partial\beta_0}=-2\sum(Y_i-\beta_0-\beta_1X_i)$，$\dfrac{\partial Q}{\partial\beta_1}=-2\sum(Y_i-\beta_0-\beta_1X_i)X_i$
  - 步驟 2（正規方程式）：$\sum(Y_i-b_0-b_1X_i)=0$，$\sum(Y_i-b_0-b_1X_i)X_i=0$
  - 步驟 3：$b_0=\bar Y-b_1\bar X$
  - 步驟 4：$b_1=\dfrac{\sum(X_i-\bar X)(Y_i-\bar Y)}{\sum(X_i-\bar X)^2}=\dfrac{S_{XY}}{S_{XX}}$
- 內容：
  - 二階導數確認是最小值
- 卡片：key「💡 直覺：兩條正規方程式就是 $\sum e_i=0$、$\sum X_ie_i=0$」
- 出處：[[least-squares-estimators]] ← Lecture 02 p.6–7
- 講者備註：第 4 步代數最容易出錯，板書時把 $\sum X_i\sum Y_i/n$ 寫成 $n\bar X\bar Y$ 幫助辨識。
- 補充：否

### S16　b₁ 是 Yᵢ 的加權和，所以不偏
- 類型：推導頁（步驟式）
- 標題：$b_1$ 是 $Y_i$ 的加權和，所以不偏
- 一句話訊息：把 $b_1$ 寫成 $\sum k_iY_i$，不偏性只要把期望值套進去。
- 公式：
  - $b_1=\sum k_iY_i,\quad k_i=\dfrac{X_i-\bar X}{\sum(X_i-\bar X)^2}$
  - 兩個性質：$\sum k_i=0,\quad \sum k_iX_i=1$
  - $E(b_1)=\sum k_i(\beta_0+\beta_1X_i)=\beta_0\sum k_i+\beta_1\sum k_iX_i=\beta_1$
- 內容：
  - $b_0=\sum l_iY_i$ 也是線性組合，同理 $E(b_0)=\beta_0$
  - 不偏：平均來說不會系統性高估或低估
- 出處：[[ls-unbiasedness-and-variance]] ← Lecture 02 p.10–11
- 講者備註：$\sum k_iX_i=1$ 最常卡住。展開：分子 $\sum(X_i-\bar X)X_i=\sum(X_i-\bar X)^2+\bar X\sum(X_i-\bar X)=\sum(X_i-\bar X)^2$（補充，非講義內容）。
- 先備提醒：期望值的線性運算
- 補充：否

### S17　X 越分散，斜率估得越準
- 類型：內容頁（左文右圖）
- 標題：$X$ 越分散，斜率估得越準
- 一句話訊息：$Var(b_1)=\sigma^2/S_{XX}$，收集資料時讓 $X$ 分散開來，斜率就更精確。
- 公式：$Var(b_1)=\sigma^2\sum k_i^2=\dfrac{\sigma^2}{S_{XX}},\qquad Var(b_0)=\sigma^2\left(\dfrac1n+\dfrac{\bar X^2}{S_{XX}}\right)$
- 內容：
  - 用到變異數相同、彼此不相關兩條假設
  - $S_{XX}$ 越大，$b_1$ 越精確
  - $\bar X$ 離 0 越遠，$b_0$ 越不精確
- 卡片：一般「🤔 想一想：要讓斜率更準，$X$ 應該集中還是分散？」
- 圖：左右兩組資料，左邊 $X$ 集中、右邊 $X$ 分散，各畫多條可能的配適線，左邊扇形較寬（示意圖）
- 出處：[[ls-unbiasedness-and-variance]] ← Lecture 02 p.11
- 講者備註：$Var(b_0)$ 講義寫「可以證明」，不推導。用右圖讓學生自己說出答案。
- 補充：否

### S18　Gauss–Markov 定理：BLUE
- 類型：內容頁（左文右卡片）
- 標題：Gauss–Markov 定理：BLUE
- 一句話訊息：在三條誤差假設下，LS 估計量是所有線性不偏估計量中變異數最小的。
- 公式：$Var(b_1)\le Var(b_1^*),\quad Var(b_0)\le Var(b_0^*)$
- 內容：
  - B 最佳：變異數最小
  - L 線性：$Y_i$ 的線性組合
  - U 不偏；E 估計量
  - 只需三條誤差假設，不需要常態
- 卡片：dark「⚠️ 誤解：BLUE 代表 LS 比所有估計量都好（只在線性不偏的估計量裡最好）」
- 出處：[[gauss-markov-theorem]] ← Lecture 02 p.12
- 講者備註：證明見 ALSM p.43–44。LS 也是一致估計量。可以連回導論的偏誤–變異取捨：有偏的估計量可能總誤差更小（補充）。
- 標籤：補充（誤解卡）

### S19　中心化的 SLR

### S23　估計 σ²：為什麼除以 n − 2？
- 類型：內容頁（左文右大數字）
- 標題：估計 $\sigma^2$：為什麼除以 $n-2$？
- 一句話訊息：估計了 $\beta_0$、$\beta_1$ 兩個參數，就少了 2 個自由度，所以 $MSE=SSE/(n-2)$。
- 公式：$s^2=\dfrac{\sum(Y_i-\bar Y)^2}{n-1}\ \longrightarrow\ s^2=MSE=\dfrac{\sum e_i^2}{n-2}=\dfrac{SSE}{n-2}$
- 內容：
  - 只看 $Y$：用 $\bar Y$ 估平均，少 1 個自由度
  - 迴歸：用 $\hat Y_i$ 取代 $\bar Y$，少 2 個
  - $MSE$ 是 $\sigma^2$ 的不偏估計，$s=\sqrt{MSE}$
  - Toluca：$SSE=54{,}825$，$MSE=54{,}825/23=2{,}384$
- 卡片：key「📌 $s=48.8$ 小時：任一批量下工時分配的標準差估計」（大數字 48.8）
- 出處：[[error-variance-mse]]、[[toluca-company]] ← Lecture 02 p.15
- 講者備註：$s$ 的單位和 $Y$ 相同，可以解讀成「觀測值通常離配適線多遠」。$E(MSE)=\sigma^2$ 的證明在 Lecture 03。
- 補充：否

### S28　常態下，最小平方 ＝ 最大概似
- 類型：推導頁（步驟式）
- 標題：常態下，最小平方 ＝ 最大概似
- 一句話訊息：常態誤差下 $b_0$、$b_1$ 就是 MLE，但 $\sigma^2$ 的 MLE 除以 $n$ 是有偏的。
- 公式：
  - $\log L=-\dfrac n2\log2\pi-\dfrac n2\log\sigma^2-\dfrac{1}{2\sigma^2}\sum(Y_i-\beta_0-\beta_1X_i)^2$
  - 對 $\beta_0,\beta_1$ 微分 → 正規方程式 → $\hat\beta_0=b_0,\ \hat\beta_1=b_1$
  - 對 $\sigma^2$ 微分 → $\hat\sigma^2=\dfrac{\sum e_i^2}{n}=\dfrac{n-2}{n}s^2$
- 內容：
  - 不論 $\sigma^2$ 多少，$\log L$ 最大都發生在平方和最小處
  - $\hat\sigma^2$ 有偏，實務上用 $MSE$
- 卡片：一般「🔍 解讀：$n=5$ 時 $\tfrac{n-2}{n}=0.6$；$n=100$ 時 0.98」
- 出處：[[mle-normal-slr]] ← Lecture 02 p.18–19
- 講者備註：重點不在推導細節，而在結論：兩種方法給同樣的 $b_0, b_1$，但 $\sigma^2$ 的分母不同。做完這頁可以回頭做練習 3 的第 2、3 小題。
