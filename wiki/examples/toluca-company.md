# Toluca 公司：批量與工時 (Toluca Company)

> 課本的招牌例題：從估計參數、算配適值與殘差，到估計誤差變異數，整個 SLR 流程都用這筆資料示範。

## 情境
Toluca 公司生產冷凍設備與替換零件。為了改善成本、找出某零件的**最佳批量**，需要知道**批量** ($X$) 與**生產該批所需工時** ($Y$) 的關係。資料是最近 25 次生產的紀錄（[[sources/lecture-02]] p.7；ALSM Table 1.1、Figure 1.10）。

## 1. 散布圖
批量與工時的關係大致是線性的，看不出離群值（[[sources/lecture-02]] p.8）。

## 2. 最小平方估計
（[[sources/lecture-02]] p.8）

| 量 | 值 |
|---|---|
| $\sum (X_i - \bar X)(Y_i - \bar Y)$ | 70,690 |
| $\sum (X_i - \bar X)^2$ | 19,800 |
| $\bar X$ | 70.0 |
| $\bar Y$ | 312.28 |

$$b_1 = \frac{70{,}690}{19{,}800} = 3.5702, \qquad b_0 = 312.28 - 3.5702(70.0) = 62.37$$

**解讀**：批量每多 1 件，平均工時估計增加 3.57 小時。這個估計只適用於資料中的批量範圍（約 20 到 120 件）。

## 3. 估計的迴歸函數與配適值
（[[sources/lecture-02]] p.13）
- $\hat Y = 62.37 + 3.5702 X$，看起來能好好描述批量與工時的統計關係。
- **批量 65 件的平均工時**：$\hat Y = 62.37 + 3.5702(65) = 294.4$ 小時。意思是：在這 25 次生產的條件下，大量生產 65 件的批次，平均工時約 294 小時。
- **第一筆資料**：$X_1 = 80$，配適值 $\hat Y_1 = 62.37 + 3.5702(80) = 347.98$ 小時；觀測值 $Y_1 = 399$，殘差 $e_1 = 51.02$（ALSM Table 1.2）。

## 4. 誤差變異數
（[[sources/lecture-02]] p.15）
- $SSE = 54{,}825$，$MSE = s^2 = 54{,}825 / 23 = 2{,}384$。
- $s = \sqrt{2{,}384} = 48.8$ 小時：任一批量下，工時分配的標準差估計值。
- 對批量 65 件：工時分配的平均估計 294.4 小時、標準差估計 48.8 小時。

## 5. 斜率的推論
（[[sources/lecture-03]] p.7–9；見 [[inference-regression-coefficients]]）
- $s^2\{b_1\} = 2{,}384 / 19{,}800 = 0.12040$，$s\{b_1\} = 0.3470$。
- **雙尾檢定** $H_0: \beta_1 = 0$（α = 0.05）：$t^* = 3.5702 / 0.3470 = 10.29 > t(0.975;\,23) = 2.069$，拒絕 $H_0$：工時與批量有線性關係。
- **單尾檢定** $H_0: \beta_1 \le 0$：$t^* = 10.29 > t(0.95;\,23) = 1.714$，拒絕 $H_0$：有正向線性關係。
- **β₁ 的 95% 信賴區間**：$3.5702 \pm 2.069(0.3470)$，即 2.85 到 4.29。批量每多 1 件，平均工時增加約 2.85 到 4.29 小時。
- R 輸出：截距 62.366（SE 26.177，t = 2.382，p = 0.0259）；斜率 3.570（SE 0.347，t = 10.290，p = 4.45e−10）。
- **檢定力**：β₁ = 1.5、σ² = 2500 時，δ = 4.22，檢定力約 0.98（見 [[power-of-slope-test]]）。

## 6. 平均反應與預測
（[[sources/lecture-03]] p.18–19；見 [[ci-mean-response]]、[[prediction-interval]]）

已知 $\hat Y = 62.37 + 3.5702X$、$MSE = 2384$、$n = 25$、$\bar X = 70$、$S_{XX} = 19{,}800$，$t(0.95;\,23) = 1.714$。

| 問題（$X_h = 100$，90%） | 點估計 | 標準誤 | 區間 |
|---|---|---|---|
| 平均工時 $E(Y_h)$ 的信賴區間 | 419.4 | $s\{\hat Y_h\} = 14.27$ | 394.9 到 443.8 |
| 下一批工時 $Y_{h(new)}$ 的預測區間 | 419.4 | — | 332.2 到 506.6 |
| 三批新批次的平均工時（補充計算） | 419.4 | $s\{predmean\} = \sqrt{998.4} = 31.6$ | 365.2 到 473.5 |

- $X_h = 65$ 的 90% 信賴區間為 277.4 到 311.4（標準誤 9.92），比 $X_h = 100$ 窄，因為 65 較接近 $\bar X = 70$。
- 預測區間最寬、三批平均居中、平均反應最窄。
- R² 雖有 0.82，下一批 100 件的預測區間仍寬達 332 到 507 小時，不足以讓管理者有效排班（[[sources/lecture-03]] p.32；見 [[high-r-squared-good-model]]）。

## 7. ANOVA、F 檢定與 R²
（[[sources/lecture-03]] p.26–31；見 [[anova-decomposition]]、[[f-test-anova]]、[[r-squared-and-correlation]]）

| 來源 | df | SS | MS | F |
|---|---|---|---|---|
| 迴歸 | 1 | 252,378 | 252,378 | 105.88 |
| 殘差 | 23 | 54,825 | 2,384 | |
| 總和 | 24 | 307,203 | | |

- $F^* = 105.9 > F(0.95;\,1,\,23) = 4.28$（補充計算），拒絕 $\beta_1 = 0$；且 $10.29^2 \approx 105.9$。
- 一般線性檢定：縮減模型 $Y = \beta_0 + \varepsilon$ 的 $SSE(R) = 307{,}203$（df 24），結果相同（見 [[general-linear-f-test]]）。
- $R^2 = 252{,}378 / 307{,}203 = 0.8215$：約 82% 的工時變異由批量解釋；$r = 0.906$。

## 8. 模型診斷
（[[sources/lecture-04]] p.7–8, 13–21；見 [[model-diagnostics]]）
- **殘差圖**：殘差對配適值、常態 QQ 圖、標準化殘差圖都沒有明顯問題（[[sources/lecture-04]] p.13–14）。
- **常態期望值**：$\sqrt{MSE} = \sqrt{2384} = 48.83$，第 $k$ 小殘差的期望值 $= 48.83\, z\left(\frac{k - 0.375}{25.25}\right)$。例如最小殘差 −83.88（排名 1）期望值 −95.91；最大殘差 103.53（排名 25）期望值 95.91（[[normal-probability-plot]]）。
- **常態檢定**（[[normality-tests]]）：常態相關係數 0.991 > 臨界值 0.959；Anderson–Darling p = 0.851、Shapiro–Wilk p = 0.863、Lilliefors p = 0.803。
- **變異數相同**：Brown–Forsythe（批量 20–70 vs. 80–120）$t^*_{BF} = 1.316$、p = 0.201（[[brown-forsythe-test]]）；Breusch–Pagan $X^2_{BP} = 0.821$、p = 0.365（[[breusch-pagan-test]]）。
- **結論**：沒有證據顯示違反常態或變異數相同的假設。

## 教學提示
- 這筆資料會一路用到推論、診斷，建議讓學生熟悉它。
- 用同一個 $X_h = 100$ 並列三種區間，最能看出信賴區間和預測區間的差別。
- 強調解讀時的兩個重點：「平均」工時、「資料範圍內」。
- 可以畫的圖：散布圖＋配適線，標出 $X = 65$ 的估計平均和 ±48.8 的範圍。
