# 最大概似法 (Maximum Likelihood)

> 找出「最有可能產生我們手上這組資料」的參數值。

## 定義
誤差分配指定之後（本課程用常態），就可以用最大概似法估計未知參數。它比最小平方法更一般（[[sources/lecture-02]] p.17）。

1. 設 $f(Y_i \mid X_i; \text{參數})$ 是 $Y_i$ 的密度函數。因為各觀測**獨立**，整組樣本的密度是各密度相乘：
   $$L(\beta_0, \beta_1, \sigma^2) = \prod_i f(Y_i \mid X_i; \beta_0, \beta_1, \sigma^2)$$
   把它看成參數的函數時，稱為**概似函數** (likelihood function)。
2. **最大概似估計 (MLE)**：讓 $L$（或 $\log L$，比較好算、答案相同）最大的參數值。也就是讓「觀察到我們實際觀察到的資料」的可能性最高的參數（[[sources/lecture-02]] p.17）。

## 例題：哪個 μ 比較合理？
常態母體，$\sigma = 10$ 已知、$\mu$ 未知。抽 $n = 3$：$Y_1 = 250$、$Y_2 = 265$、$Y_3 = 259$。比較 $\mu = 230$ 與 $\mu = 259$（[[sources/lecture-02]] p.17–18；ALSM Figure 1.13）：

| | $\mu = 230$ | $\mu = 259$ |
|---|---|---|
| $f_1$（$Y_1 = 250$） | 0.005399 | 0.026609 |
| $f_2$（$Y_2 = 265$） | 0.000087 | 0.033322 |
| $f_3$（$Y_3 = 259$） | 0.000595 | 0.039894 |
| 概似值 $L(\mu)$（三者相乘） | $0.279 \times 10^{-9}$ | $0.0000354$ |

$L(259)$ 遠大於 $L(230)$，所以 $\mu = 259$ 和資料一致得多。

> 註：講義 p.18 第一列把 $\mu = 259$ 的 $f_1$ 印成 $f_2$，依 p.17 的計算更正（2026-11-24 經使用者確認）。

## 在迴歸中的應用
SLR 加上常態誤差時，$\beta_0$、$\beta_1$ 的最大概似估計就是最小平方估計，見 [[mle-normal-slr]]。

## 教學提示
- 學生常卡關：分不清「機率」和「概似」。強調：資料固定、讓參數變動，看哪個參數讓這組資料最可能出現。
- 例題可以讓學生先猜 $\mu$ 是 230 還是 259，再算概似值確認。
- 可以畫的圖：兩條不同中心的常態曲線，標出三個觀測值的高度。
